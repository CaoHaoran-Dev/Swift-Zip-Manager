# Swift Zip Manager

macOS 归档文件管理器，使用 Swift + SwiftUI 构建。

> 当前版本：1.0.0-Beta.9 · 开发中

## 功能特性

- 解压 / 创建 ZIP、TAR、GZ、7Z、RAR
- 加密归档（ZIP / 7Z / RAR 支持密码保护）
- 归档内容浏览（列表 / 网格视图）
- 单文件提取 / 全部提取 / 从归档中删除文件
- 带边栏的文件浏览器（桌面、文稿、下载、个人、宗卷）
- 拖放支持（向新建归档添加文件）
- 最近文件历史
- 一键安装 7zz 和 RAR 工具
- 通过 GitHub API 自动检查更新
- 多语言支持（English、简体中文、繁體中文）
- 开发者模式（调试工具、实验性功能、高级设置）
- 键盘快捷键支持

## 技术栈

- Swift 5 + SwiftUI
- Process / Pipe（命令行工具调用）
- CryptoKit（AES-256-GCM 加密）
- macOS 13.5+

## 安装

从 Releases 下载 DMG，将应用拖入 Applications 文件夹。

> 如果首次启动时看到安全警告，请前往“系统设置 > 隐私与安全性”，点击“仍要打开”。

## 使用说明

### 键盘快捷键

| 快捷键 | 操作 |
|--------|------|
| `⌘A` | 新建归档 |
| `⌘O` | 打开归档 |
| `⌘E` | 提取选中项 |
| `⌘⇧E` | 全部提取 |
| `⌘,` | 打开设置 |
| `⌘?` | 打开帮助 |
| `⌘W` | 关闭窗口 |
| `⌘R` | 在 Finder 中显示 |

### 快速开始

1. 点击“打开归档”或按 `⌘O` 打开现有归档
2. 点击“新建归档”或按 `⌘A` 创建新归档
   - 从 Finder 拖放文件到窗口，或点击“添加文件”/“添加文件夹”
   - 从下拉菜单中选择格式（ZIP、TAR、GZ、7Z、RAR）
   - 可选设置加密密码（含密码强度指示器）
   - 目标路径会被记住以便下次使用
3. 以列表或网格视图浏览归档内容
4. 选中文件后使用 `⌘E` 提取，或右键查看更多选项
5. 双击文件夹进入，双击归档打开

### 外部工具

- **7zz**：解压 ZIP、7Z、RAR 及创建 7Z 所需
- **RAR**：创建 RAR 所需
- 两个工具均可从“设置 > 工具”中一键安装
- SHA256 校验确保下载完整性（仅 7zz，RAR 跳过校验）

### 开发者模式

在“关于”页面点击版本号 5 次即可启用。开发者模式提供：
- **调试**工具：日志记录、显示隐藏文件、自定义工具路径、测试操作
- **实验性**功能：并行提取、新提取引擎、快速 ZIP 处理
- **不稳定**功能：异步文件写入、内存提取（请谨慎使用）
- **高级**设置：内存限制、自定义临时目录、最大并行操作数

## 更新系统

- **自动检查**：每 5 次启动或每 24 小时自动检查更新
- **手动检查**：在设置中点击“检查更新”或从菜单按 `⌘U`
- **双通道**：稳定版（推荐）或 Beta/RC
- **发布说明**：以 Markdown 格式显示
- **SHA256 校验**：通过 GitHub API `digest` 字段验证下载完整性
- **一键安装**：直接从 GitHub Releases 下载并安装更新
