# Swift Zip Manager

macOS 压缩文件管理器，Swift + SwiftUI 实现。

> 当前版本：1.0.0-Beta.7 · 开发中

## 功能

- 解压 / 创建 ZIP、TAR、GZ、7Z、RAR
- 加密归档（ZIP / 7Z / RAR 支持密码保护）
- 归档内容浏览（列表 / 网格视图）
- 单文件提取 / 全部提取 / 删除归档内文件
- 文件浏览器（侧边栏快速访问桌面、文稿、下载、个人、外置磁盘）
- 拖拽支持- 最近文件记录
- 一键安装 7zz 和 RAR 工具
- 自动检查更新（GitHub API）
- 多语言支持（英文、简体中文、繁体中文）
- 开发者模式（调试工具、实验性功能、高级设置）
- 键盘快捷键支持

## 技术栈

- Swift 5 + SwiftUI
- Process / Pipe（调用系统命令行工具）
- CryptoKit（AES-256-GCM 加密）
- macOS 13.5+

## 安装

从 Releases 下载 DMG，将 App 拖入 Applications 文件夹。

> 首次启动如遇安全警告，请前往「系统设置 > 隐私与安全性」点击「仍要打开」。

## 使用说明

**键盘快捷键**

| 快捷键 | 操作 |
|--------|------|
| `⌘A` | 新建归档 |
| `⌘O` | 打开归档 |
| `⌘E` | 提取选中文件 |
| `⌘⇧E` | 提取全部 |
| `⌘,` | 打开设置 |
| `⌘?` | 打开帮助 |
| `⌘W` | 关闭窗口 |
| `⌘R` | 在 Finder 中显示 |

**快速上手**

1. 点击「打开归档」或按 `⌘O` 打开现有归档文件
2. 点击「新建归档」或按 `⌘A` 创建新归档
   - 从访达拖拽文件到窗口内，或点击「添加文件」
   - 从下拉菜单中选择格式（ZIP、TAR、GZ、7Z、RAR）
   - 可选设置加密密码
   - 保存路径会自动记住上次选择的位置
3. 以列表或网格视图浏览归档内容
4. 选中文件后按 `⌘E` 提取，或右键点击查看更多选项
5. 双击文件夹进入，双击归档文件打开

**外部工具**

- 7zz 用于 ZIP、7Z、RAR 提取及 7Z 创建
- RAR 工具用于 RAR 创建
- 两个工具都可以在「设置 > 工具」中一键安装

**开发者模式**

在关于页面点击版本号 5 次即可开启。
